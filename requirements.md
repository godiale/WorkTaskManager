As user I want to manage my work tasks via browser application, running locally and having python backend.

Each task has following attributes:
* ID - unique numeric positive number, doesn't change.
* Labels - set of strings.
* Deadline - date field (optional)
* Review - date field (optional)
* Description - text multi-line field.
* Rank - numeric positive number

As user I want to see my tasks in form of a grid.
Tasks should be displayed in descending ranks order.
Columns should be displayed in the following order:
* ID
* Labels
* Deadline
* Review
* Button with up arrow symbol (Move Task Up)
* Button with down arrow symbol (Move Task Down)
* Button with double-up arrow symbol (Move Task Top)
* Description

"Add New Task" button should be above the grid left, and "Search" control above the grid right to "Add new Task" button.

As user I want to add new task by clicking "Add New Task" button. New task placeholder appears first in the grid, with autogenerated ID, and rank, greater then ranks of other tasks. Other attributes should be empty for new task.

As user I want to edit each attribute of each task, clicking to cell of the grid, typing in value, pressing Enter. For Description attribute Ctrl+Enter should be used to save the value of attribute.

As user I want to search for task, by typing in search word in "Search" field. After typing in 3 characters, only tasks with search 3-character search word should be left in the grid. After typing in 4th character, only containing 4-character word and so on. Search should be done in each attribute, excluding rank.

As user I want to move task one row up by pressing "Move Task Up" button. Ranks should be changed accordingly.

As user I want to move task one row down by pressing "Move Task Down" button. Ranks should be changed accordingly.

As user I want to move task to top by pressing "Move Task Top" button. Ranks should be changed accordingly.
